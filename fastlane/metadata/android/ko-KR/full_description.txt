<b>사진 한 장이 사는 곳을 알려줄 수 있습니다.</b>
사진과 동영상에는 정확한 GPS 위치, 날짜와 시간, 휴대전화 제조사와 모델이 담길 수 있습니다. 원본 파일을 받은 사람은 누구나 이를 읽을 수 있습니다.
Redact는 메타데이터와 EXIF를 지우는 앱입니다. 파일이 무엇을 드러내는지 보여 주고, 기기 안에서 모두 지워 줍니다.
계정도, 업로드도, 광고도, 데이터 수집도 없습니다.

<b>이런 분께 필요합니다</b>
• 당근, eBay, 마켓플레이스에서 집 주소를 노출하지 않고 판매할 때
• 데이트 상대, 집주인, 처음 만난 사람에게 사진을 보낼 때
• 아이, 집, 자동차 사진을 공유할 때
• 취재원을 보호해야 하는 기자와 활동가
• 숨은 정보가 그대로 남는 이메일이나 파일로 사진을 보낼 때

<b>스캔으로 사진이 드러내는 정보 확인</b>
• 숨은 항목을 모두 보여 주는 깔끔하고 검색 가능한 EXIF 뷰어
• 촬영 위치를 드러내는 항목에는 위치 배지가 붙습니다

<b>정리로 GPS, 위치, EXIF 데이터 삭제</b>
• 사진과 동영상을 한 번에 최대 100개까지 정리
• GPS와 지오태그, 기기 정보, 시간 정보 삭제
• XMP, IPTC, 주석, 동영상 태그 삭제
• 미리보기 이미지와 모션 포토 영상 같은 숨은 데이터 삭제
• 화질 그대로: 사진을 다시 압축하지 않습니다
• 원하면 촬영 날짜, 위치, 카메라 설정 또는 모션 포토의 동영상 유지
• 무엇을 지웠는지 정확히 알려 줍니다
• 휴지통으로 옮기도록 설정하지 않는 한 원본은 그대로 남습니다

<b>어느 앱에서나 안전하게 공유</b>
갤러리나 다른 앱에서 사진이나 동영상을 Redact로 공유하면, 정리한 파일을 바로 공유 메뉴로 돌려줍니다.
먼저 확인하려면 'Redact로 스캔'으로 공유하세요.

<b>형식 변환과 가리기</b>
• HEIC를 JPG로 변환, PNG와 WebP 이미지도 지원
• H.264, H.265, VP9, AV1 동영상 변환
• 변환한 파일은 모두 정리되고 검사됩니다
• 가리기로 얼굴, 번호판, 주소를 모자이크하거나 검게 칠하거나 흐리게 처리

<b>처음부터 개인정보 보호</b>
• 모든 작업이 휴대전화에서 이루어지며 인터넷이 필요 없습니다
• 광고, 분석, 추적, 계정이 없습니다
• 사진, 동영상, 개인 정보는 절대 수집하거나 공유하지 않습니다
• GPL-3.0 오픈소스로, 누구나 GitHub에서 코드를 볼 수 있습니다
• 시스템 파일 선택기로 작동하므로 전체 사진 보관함 접근 권한은 선택 사항입니다
• 선택 사항인 비정상 종료 보고서는 직접 켜기 전까지 꺼져 있습니다

<b>편리한 기능</b>
• 빠른 설정 타일과 홈 화면 바로가기
• 저장 폴더 지정과 원본 파일 이름 유지
• 엄격한 정리
• 스크린샷과 최근 앱에서 Redact 숨기기
• 복사한 메타데이터 자동 삭제
• 휴대전화에서만 집계되는 통계

<b>한 번 구매로 계속 사용</b>
구독, 광고, 인앱 구매가 없습니다. 구매가 독립 개발자에게 힘이 됩니다.

한국어, 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 러시아어, 일본어, 중국어(간체·번체), 힌디어, 아랍어를 지원합니다.
