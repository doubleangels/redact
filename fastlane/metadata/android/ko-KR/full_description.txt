<b>사진 한 장이 사는 곳을 알려줄 수 있습니다.</b>

<p>휴대전화로 찍은 사진에는 촬영 위치의 정확한 GPS 좌표, 날짜와 시간, 휴대전화 제조사와 모델 같은 숨은 메타데이터가 담길 수 있습니다. 원본 파일을 받은 사람은 누구나 이를 읽을 수 있습니다. Redact는 사진이나 동영상이 무엇을 드러내는지 보여 주고, 기기 안에서 모두 지워 줍니다. 계정도, 업로드도, 광고도, 데이터 수집도 없습니다.</p>

<b>이런 분께 필요합니다</b>
<ul>
<li>당근, eBay, 마켓플레이스에서 집 주소를 노출하지 않고 판매할 때</li>
<li>데이트 상대, 집주인, 처음 만난 사람에게 사진을 보낼 때</li>
<li>아이, 집, 자동차 사진을 공유할 때</li>
<li>취재원을 보호해야 하는 기자와 활동가</li>
<li>숨은 정보가 그대로 남는 이메일이나 파일로 사진을 보낼 때</li>
</ul>

<b>확인하기: 스캔</b>
<p>사진이나 동영상을 열면 숨은 항목이 모두 검색 가능한 목록으로 깔끔하게 표시됩니다. 촬영 위치를 드러내는 항목에는 위치 배지가 붙습니다.</p>

<b>지우기: 정리</b>
<p>사진과 동영상을 한 번에 최대 20개까지 정리하세요. Redact는 GPS, 기기 정보, 시간 정보, XMP, IPTC, 동영상 태그를 지우고 무엇을 지웠는지 정확히 알려 줍니다. 휴지통으로 옮기도록 설정하지 않는 한 원본은 그대로 남습니다.</p>

<b>어느 앱에서나 안전하게 공유</b>
<p>갤러리나 다른 앱에서 사진이나 동영상을 Redact로 공유하면, 정리한 파일을 바로 공유 메뉴로 돌려줍니다. 먼저 확인하려면 'Redact로 스캔'으로 공유하세요.</p>

<b>형식 변환</b>
<p>JPEG, PNG, WebP, HEIC 이미지와 H.264, H.265, VP9, AV1 동영상을 지원합니다. 변환한 파일은 모두 정리되고 검사됩니다.</p>

<b>처음부터 개인정보 보호</b>
<ul>
<li>모든 작업이 휴대전화에서 이루어집니다. 정리, 스캔, 변환에 인터넷이 필요 없습니다.</li>
<li>광고, 분석, 추적, 계정이 없습니다</li>
<li>Google Play 데이터 보안: 수집하는 데이터 없음, 공유하는 데이터 없음</li>
<li>GPL-3.0 오픈소스로, 누구나 GitHub에서 코드를 볼 수 있습니다</li>
<li>시스템 파일 선택기로 작동하므로 전체 사진 보관함 접근 권한은 선택 사항입니다</li>
<li>선택 사항인 비정상 종료 보고서는 직접 켜기 전까지 꺼져 있습니다</li>
</ul>

<b>편리한 기능</b>
<p>빠른 설정 타일, 홈 화면 바로가기, 저장 폴더 지정, 원본 파일 이름 유지, 엄격한 정리, 스크린샷과 최근 앱에서 Redact 숨기기, 복사한 메타데이터 자동 삭제.</p>

<b>한 번 구매로 계속 사용</b>
<p>구독, 광고, 인앱 구매가 없습니다. 구매가 독립 개발자에게 힘이 됩니다.</p>
