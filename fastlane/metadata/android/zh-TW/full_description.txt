<b>你的照片可能洩露你的住址。</b>
每張照片和每段影片都可能帶有精確的 GPS 位置、日期與時間，以及手機的品牌與型號。任何拿到原始檔案的人都能讀取這些資訊。
Redact 是一款中繼資料與 EXIF 清除工具。它會顯示檔案洩露了什麼，並在你的裝置上將其清除。
不需帳號、不上傳、沒有廣告，也不收集任何資料。

<b>適合誰</b>
• 在蝦皮、eBay 或 Marketplace 上賣東西，又不想透露住家地址
• 傳照片給約會對象、房東或剛認識的人
• 分享孩子、住家或汽車的照片
• 需要保護消息來源的記者與社運人士
• 以電子郵件或檔案形式傳送照片，這會保留所有隱藏資訊

<b>用掃描看清照片洩露了什麼</b>
• 在清楚、可搜尋的 EXIF 檢視器中顯示每個隱藏欄位
• 凡是能看出拍攝地點的內容都會標上「位置資訊」標記

<b>用清理移除 GPS、位置與 EXIF 資料</b>
• 一次最多清理 100 張照片與影片
• 移除 GPS 與地理標記、裝置資訊與時間戳記
• 移除 XMP、IPTC、註解與影片標籤
• 移除隱藏的額外內容，例如預覽圖與動態相片影片
• 畫質完整保留：相片絕不會被重新壓縮
• 可選擇保留拍攝日期、位置、相機設定或動態相片的影片
• 明確告訴你移除了什麼
• 除非你讓 Redact 把原始檔案移到垃圾桶，否則原始檔案不會被更動

<b>從任何應用程式安全分享</b>
從相簿或其他應用程式把照片或影片分享給 Redact，它會清理檔案並直接交回分享選單。
也可以分享到「使用 Redact 掃描」先檢查一下。

<b>轉換格式，遮蔽細節</b>
• HEIC 轉 JPG，並支援 PNG 與 WebP 圖片
• 轉換 H.264、H.265、VP9 與 AV1 影片
• 每個轉換後的檔案都會被清理並檢查
• 遮蔽可對人臉、車牌與地址打馬賽克、塗黑或模糊處理

<b>從設計上保護隱私</b>
• 一切都在手機上完成，不需要連網
• 沒有廣告、分析、追蹤，也不需帳號
• 絕不收集或分享你的相片、影片和個人資訊
• 以 GPL-3.0 開放原始碼，任何人都能在 GitHub 上查看程式碼
• 使用系統檔案選擇器，存取整個相簿的權限是選用的
• 選用的當機報告預設關閉，由你決定是否開啟

<b>實用功能</b>
• 快速設定圖塊與主畫面捷徑
• 自訂輸出資料夾與保留原始檔名
• 嚴格清理
• 在螢幕截圖與最近使用中隱藏 Redact
• 自動清除已複製的中繼資料
• 只在你的手機上進行的「統計」
