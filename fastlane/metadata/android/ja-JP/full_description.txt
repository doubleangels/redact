<b>写真から、あなたの住所がわかってしまうかもしれません。</b>
写真や動画には、正確な GPS 位置情報、撮影日時、スマートフォンのメーカーや機種が含まれていることがあります。元のファイルを受け取った人は誰でもそれを読み取れます。
Redact はメタデータと EXIF を削除するアプリです。ファイルから何がわかるかを表示し、すべて端末内で削除します。
アカウント不要、アップロードなし、広告なし、データ収集なし。

<b>こんな方に</b>
• メルカリ、eBay、マーケットプレイスで自宅の場所を知られずに出品したい
• デートの相手や大家さん、知り合ったばかりの人に写真を送る
• 子どもや自宅、車の写真を共有する
• 情報源を守る必要があるジャーナリストや活動家
• 写真をメールやファイルとして送る（隠れた情報がすべて残ります）

<b>スキャンで写真からわかることを確認</b>
• 隠れた項目をすべて表示する、見やすく検索できる EXIF ビューア
• 撮影場所がわかる項目には「位置情報」バッジが付きます

<b>クリーンで GPS・位置情報・EXIF を削除</b>
• 写真と動画を最大 100 件まとめてクリーン
• GPS やジオタグ、端末情報、日時を削除
• XMP、IPTC、コメント、動画のタグを削除
• プレビュー画像やモーションフォトの動画など、隠れた追加データを削除
• 画質はそのまま：写真を再圧縮しません
• 必要なら撮影日時、位置情報、カメラ設定、モーションフォトの動画を残せます
• 何を削除したかを正確に表示
• 元のファイルはそのまま残ります（ゴミ箱に移動するよう設定した場合を除く）

<b>どのアプリからでも安全に共有</b>
ギャラリーや他のアプリから写真や動画を Redact に共有すると、クリーンしたファイルをそのまま共有メニューに戻します。
「Redact でスキャン」に共有して、先に中身を確認することもできます。

<b>形式を変換、見せたくない部分は隠す</b>
• HEIC を JPG に変換、PNG や WebP の画像にも対応
• H.264、H.265、VP9、AV1 の動画を変換
• 変換したファイルはすべてクリーンされ、確認されます
• 「隠す」で顔やナンバープレート、住所にモザイク、黒塗り、ぼかしをかけられます

<b>プライバシー最優先の設計</b>
• すべてスマートフォン内で動作し、インターネット接続は不要です
• 広告、分析、トラッキング、アカウントは一切ありません
• 写真、動画、個人情報が収集・共有されることはありません
• GPL-3.0 のオープンソース。誰でも GitHub でコードを確認できます
• システムのファイル選択で動作するため、ライブラリ全体へのアクセスは任意です
• 任意のクラッシュレポートは、オンにするまでオフのままです

<b>便利な機能</b>
• クイック設定タイルとホーム画面のショートカット
• 保存先フォルダの指定と元のファイル名の保持
• 厳格クリーン
• スクリーンショットと履歴での非表示
• コピーしたメタデータの自動消去
• お使いのスマートフォン内だけで集計される「統計」

サブスクリプション、広告、アプリ内購入はありません。ご購入が個人開発者の支えになります。
